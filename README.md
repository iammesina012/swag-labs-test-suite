# Swag Labs (SauceDemo) Test Suite — Manual Testing

This is a personal practice project. I tested SauceDemo, a demo e-commerce website made for QA practice, and wrote test cases and bug reports based on what I found.

*Note: Since this is a demo site with no official requirements document, I wrote my own requirements (with some help from AI) based on how the site is expected to behave, then used those as the basis for testing.*

## Purpose

I made this project to practice manual testing skills:
- Creating test scenarios covering positive, negative, and edge cases
- Writing clear test steps and using appropriate test data
- Documenting expected and actual results
- Using exploratory and ad-hoc testing as part of my manual testing practice
- Identifying and reporting bugs with clear reproduction steps, severity, and priority

## What I Tested

I tested 9 parts of the site, with 125 test cases and 15 documented bug reports:

| Page/Section | What I Checked |
|---|---|
| Login | Valid/invalid login, required fields, locked-out user, session behavior, and edge cases |
| Sidebar | Menu links and navigation |
| All Items | Product list, product information, sorting, Add to Cart, Remove, and Product Details |
| Your Cart | Cart items, product navigation, removing items, and checkout access |
| Checkout: Information | Required fields, input validation, and navigation |
| Checkout: Overview | Order summary and checkout information |
| Checkout: Complete | Order confirmation, Back Home, and order PDF |
| Footer | Footer links |
| Security | Authentication and access behavior |

Test cases includes: Test Case ID, Test Scenario, Precondition, Test Data, Test Steps, Expected Result, Actual Result, and Status.

Bug reports includes: Bug ID, Bug Title, Module, Test Account, Environment, Steps to Reproduce, Expected Result, Actual Result, Severity, and Priority.

## Tools Used

- Excel — for writing test cases and bug reports
- Microsoft Edge — for test execution
- Manual testing only, no automation
